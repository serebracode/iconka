# Iconka — комплект икон: источники, подготовка и QA

Этот документ — обязательный регламент для каждой новой или заменяемой иконы. Он дополняет `AGENTS.md`; если правила расходятся, для отбора источника, подготовки изображений и metadata применяется этот документ.

## Главный принцип

Сначала выбирается **конкретный музейный памятник** с подтверждёнными provenance, датировкой, правами и качественным master-файлом. Потом из него собирается комплект.

Не принимать решение по принципу: «красивая картинка нашлась — добавим».

## Приоритет источников

1. Petit Palais / Paris Musées — основной системный источник: карточки, IIIF, Open Content/CC0 для подходящих предметов.
2. Cleveland Museum of Art — единичные сильные объекты, Open Access / CC0.
3. The Metropolitan Museum of Art — прежде всего ранняя Византия; включать только после проверки именно православной атрибуции.
4. Walters Art Museum — византийские, греческие, русские иконы; фильтровать декоративные, западные и смешанные традиции.
5. Finnish National Gallery / Sinebrychoff — резерв для русской и восточно-христианской иконописи.
6. Wikimedia Commons — только fallback: файл должен вести к понятному музейному master и иметь прозрачные rights.

Не использовать как конечный источник Pinterest, Tumblr, блоги, Google Images, скриншоты, Pravmir или Icon-Art.info, если доступна первичная музейная карточка.

## Критерии выбора

- Православная иконописная традиция: византийская, греческая, критская, русская, сербская, грузинская, балканская или другая подтверждённая восточно-христианская.
- Обычный временной приоритет: XII–XVI века. XVII век допустим для сильного сюжета; XVIII–XIX — для важных поздних почитаемых типов.
- Не добавлять бессмысленный дубль: второй Николай, Елеуса или Пантократор нужен только при иной школе, типе, эпохе, композиции или значении памятника. Более качественный экземпляр одного типа обычно заменяет существующий.
- Предпочитать CC0 / Public Domain от музея; затем CC BY; CC BY-SA — только при осознанной необходимости.
- Master: желательно минимум 2000 px по длинной стороне, предпочтительно 3000+ px; без watermark, повторного JPEG-сжатия, сторонней цветокоррекции и искусственного sharpening.
- Объект должен быть снят фронтально, с различимым внешним контуром, без тяжёлой рамы, постамента и перекрытий. Это критично для Candle Mode.
- Почитаемый тип не равен оригиналу чудотворной иконы. Если это поздний список, текст так и говорит: «представляет иконографический тип», а не выдаёт его за первообраз.

## Обязательный комплект

Для каждой **новой или заменяемой** иконы создать все пять файлов:

```text
icons/<slug>.jpg
icons/preview/<slug>_preview.jpg
icons/loading/<slug>_loading.jpg
icons/candle/<slug>.webp
icons/png/<slug>.png
```

### 1. Main — `icons/<slug>.jpg`

- Цветовой master для detail screen.
- Полный объект, без искажения пропорций и без ненужного унифицирующего crop.
- Чистый край: без чёрной рамки, подложки, стойки, клипс, watermark и чужого фона.
- Сохраняет реальную геометрию доски, сколы, наклон и исторический край.
- Не превращать старую неровную доску в идеальный прямоугольник.

### 2. Preview — `icons/preview/<slug>_preview.jpg`

- Отдельно скомпонованный квадрат для каталога, не побочный ресайз loading.
- Заполняет квадрат без пустых полей; безопасно читает главный образ на малом размере.
- Визуально не выдаёт чёрную рамку или фон за часть иконы.

### 3. Loading — `icons/loading/<slug>_loading.jpg`

- Микрокопия main для progressive loading и свайпа.
- Та же композиция и то же соотношение сторон, что у main.
- Длинная сторона около 48 px.
- Никогда не подменяется preview и никогда не берётся от другой иконы.
- В `loading_image` добавляется новый cache key `?v=<hash>`.

### 4. Candle image — `icons/candle/<slug>.webp`

- Видимая цветная икона в Candle Mode.
- WebP с реальной прозрачностью, мягким антиалиасным внешним краем.
- Убирает музейный фон и чёрную кайму, но не вырезает живопись, золото, нимб, кант или сколы.
- Контур строится из этого конкретного объекта. Общий шаблон, alpha другой иконы и прямоугольная заглушка запрещены.

### 5. Cutout master — `icons/png/<slug>.png`

- PNG с индивидуальной настоящей alpha-маской этого же объекта.
- Используется для shadow / projection / masks.
- Контур совпадает с `candle_image`, но остаётся надёжным lossless master.
- Нельзя «заливать» внутренние участки картинки прозрачностью; прозрачным является только внешний фон.
- Нельзя оставлять чёрный/белый halo, грязные полупрозрачные пиксели, куски рамы или фоновые артефакты.

## Обтравка: обязательные проверки

Для каждого master отдельно проверить на сером и чёрном фоне:

1. Alpha принадлежит именно этой иконе и нигде не переиспользована.
2. Внешний силуэт соответствует доске/объекту, включая реальные неровности.
3. Нет чёрной рамки, матового ореола, фона, креплений или случайных островков.
4. Не съедены края, золотой кант, нимбы, живописные фрагменты и внутренняя часть объекта.
5. `candle_image` и `cutout_master` совпадают по масштабу, расположению и внешнему контуру.
6. В реальном Candle Mode свет, тень и projection опираются на контур, а не на прямоугольник.

Автоматическая обтравка — только первый проход. Если QA не пройден, файл не коммитится.

## Metadata

Каждая запись в `data/icons.json` должна содержать:

```json
{
  "id": 29,
  "title": "Название",
  "title_short": "Короткое название",
  "image": "./icons/example.jpg",
  "loading_image": "./icons/loading/example_loading.jpg?v=HASH",
  "preview_image": "./icons/preview/example_preview.jpg",
  "candle_image": "./icons/candle/example.webp",
  "cutout_master": "./icons/png/example.png",
  "image_source": "https://museum.example/object/123",
  "image_source_label": "Изображение: Museum Name",
  "image_credit": "Museum Name · CC0",
  "author_full": "Неизвестный мастер",
  "date": "XVI век",
  "material": "Дерево, темпера",
  "size": "00 × 00 см",
  "location": "Museum Name, City",
  "description_full": "Короткое содержательное описание.",
  "rights": "CC0 / Public Domain"
}
```

- `image_source` — только карточка конкретного объекта (или конкретная Commons file page), не homepage, статья или поисковая выдача.
- Не угадывать автора, дату, размер, музей, лицензию и provenance. Если данных нет — писать «Неизвестно».
- Source, credit и rights фиксируются до коммита.

## Рабочий процесс

1. Вход: сюжет, название, ссылка, изображение или просьба подобрать N икон.
2. Поиск: 2–4 кандидата на сюжет, с первичным музейным источником.
3. Выбор: сравнить православную атрибуцию, эпоху, школу, значение, отсутствие дубля, права, master и пригодность для обтравки.
4. Скачать master: IIIF / музейный high-resolution JPEG или TIFF, не preview и не скриншот.
5. Собрать пять изображений из одного master.
6. Подготовить и проверить metadata и текст описания.
7. QA: JSON, пути, ID, файлы, alpha, preview, progressive loader, detail, swipe, Info и Candle Mode.
8. Коммит: отдельная ветка; без изменения `index.html`, жестов, свечи или других runtime-файлов.

## Целевое качество каталога

Лучше 30–40 документированных икон с понятными правами, первичным музейным source и индивидуальными alpha-assets, чем сотня случайных изображений с мутным происхождением.
