# Iconka

**Iconka / «Иконка»** — Telegram Mini App и статическое web-приложение для просмотра образцов православной иконописи.

Проект задуман как спокойный просветительский каталог: показать подлинные произведения, дать базовый исторический контекст и вернуть слову «иконка» его исходный смысл — образ, а не универсальное название любой маленькой графики интерфейса.

Текущая пользовательская версия: **1.0**.

---

## Текущее состояние

Проект находится в стадии **стабилизации и наполнения контентом**.

На текущем `main`:

- 18 икон в каталоге;
- основной runtime считается рабочим baseline;
- ближайшая задача — расширить каталог примерно ещё на десяток икон;
- архитектуру, жесты, загрузку, навигацию и режим свечи без отдельной причины не меняем.

Правила для AI/coding-agent находятся в корневом [`AGENTS.md`](./AGENTS.md).

## Что умеет приложение

### Стартовый экран

При первом запуске или перезагрузке показывается стартовый экран:

- знак приложения;
- логотип «Иконка»;
- подсказка «Коснитесь, чтобы начать»;
- переход в каталог по касанию;
- резервный автоматический переход через несколько секунд.

Стартовый экран не является обычным экраном навигации: после входа логотип на остальных экранах возвращает пользователя в каталог.

### Каталог

Каталог:

- загружается из `data/icons.json`;
- сортируется по названию независимо от порядка записей в JSON;
- содержит поиск;
- использует квадратные preview-изображения;
- показывает ссылку «О проекте» и текущую версию приложения.

### Экран иконы

Для выбранной иконы доступны:

- полноразмерное изображение;
- название и дата;
- горизонтальный свайп к предыдущей/следующей иконе;
- двойной тап для увеличения ×2;
- панорамирование увеличенного изображения;
- Share;
- Info;
- «Режим свечи».

### Info

Info раскрывается внутри экрана иконы и содержит:

- полное название;
- дату;
- описание;
- автора;
- размер;
- технику;
- местонахождение;
- источник изображения;
- credit / лицензионную информацию;
- ссылку «О проекте»;
- версию приложения.

Верхняя и нижняя fade-шторки появляются только когда соответствующая часть текста действительно скрыта прокруткой.

### Share

Используется нативный Web Share API, если он доступен. В Telegram предусмотрен fallback через Telegram share URL.

### Режим свечи

«Режим свечи» — отдельное визуальное состояние сцены, а не простое наложение PNG.

Он включает:

- отдельное тело свечи;
- видео пламени;
- окружающее тёплое освещение;
- локальный свет на поверхности иконы;
- затемнение краёв и верхней части;
- виньетку;
- локальный ореол;
- тень / проекцию иконы;
- движение света и тени, синхронизированное с пламенем;
- foreground-слои атмосферы.

Во время режима свечи обычные кнопки и логотип скрываются. Касание сцены закрывает режим.

Подробная карта слоёв и инвариантов: [`docs/icon-screen-layers.md`](./docs/icon-screen-layers.md).

## Загрузка изображений

Экран иконы использует прогрессивную загрузку.

Порядок:

1. `loading_image` декодируется как миниатюра полного изображения.
2. Из неё формируются ступени примерно **12 → 24 → 48 px** по длинной стороне.
3. Ступени последовательно показываются как крупная пиксельная мозаика.
4. Параллельно загружается основной `image`.
5. После декодирования полный JPEG заменяет миниатюру.

Асинхронная подмена защищена токенами отмены, чтобы предыдущая икона не могла «догрузиться» поверх новой после свайпа или входа в Candle Mode.

## Свайп между иконами

Каталог и экран иконы используют один алфавитный порядок.

При открытии и после каждого свайпа приложение заранее декодирует loading-preview соседних икон.

Во время перехода:

- текущая карточка временно клонируется;
- новая карточка готовится за пределами экрана;
- старая и новая карточки одновременно сдвигаются;
- переход длится около 320 мс;
- повторный свайп и zoom блокируются до завершения перехода.

Это сделано специально, чтобы при свайпе не вспыхивало изображение предыдущей иконы.

## Адаптивность и ориентация

Приложение работает с Telegram viewport и safe-area.

Используются:

- `viewportStableHeight` Telegram, когда доступен;
- `visualViewport` как web-fallback;
- CSS safe-area inset;
- общая контентная колонка до 560 px;
- отдельная художественная ширина сцены иконы.

Политика ориентации:

- телефон — портретный режим;
- планшет — горизонтальный режим;
- wide/web layout масштабируется в пределах установленной художественной сцены.

## Telegram Mini App

При наличии `window.Telegram.WebApp` приложение:

- вызывает `ready()`;
- разворачивается через `expand()`;
- пытается запросить fullscreen;
- отключает вертикальные Telegram-swipes;
- настраивает чёрный header/background;
- использует BackButton;
- реагирует на изменения viewport и safe-area;
- учитывает параметры Telegram theme;
- использует Telegram как fallback для Share.

Приложение также может открываться как обычная web-страница.

## Данные икон

Источник данных:

`data/icons.json`

Текущая запись обычно содержит:

```json
{
  "id": 21,
  "title": "Полное название",
  "title_short": "Короткое название",
  "image": "./icons/example.jpg",
  "loading_image": "./icons/loading/example_loading.jpg?v=<cache-key>",
  "image_source": "https://...",
  "image_source_label": "Изображение: ...",
  "image_credit": "...",
  "author_full": "...",
  "date": "...",
  "material": "...",
  "size": "...",
  "location": "...",
  "description_full": "...",
  "rights": "..."
}
```

Не все поля обязательны для каждой записи.

Дополнительно могут использоваться:

- `preview_image` — явный путь к catalog preview;
- `candle_image` — отдельная версия для Candle Mode;
- `cutout_master` — alpha-master для масок и проекции.

## Набор assets одной иконы

Для обычной новой иконы нужны три файла.

### Основное изображение

```text
icons/<slug>.jpg
```

Полное экранное изображение.

### Preview каталога

```text
icons/preview/<slug>_preview.jpg
```

Квадратная миниатюра для списка.

Если `preview_image` не задан явно, runtime выводит путь автоматически из `image`.

### Loading image

```text
icons/loading/<slug>_loading.jpg
```

Полноформатная микрокопия иконы с той же композицией и пропорциями, что и основной JPEG. Длинная сторона следует текущему соглашению примерно 48 px.

Loading image и catalog preview — разные файлы с разной задачей.

---

## Специальные Candle assets

Обычная икона не обязана иметь отдельную candle-версию: если `candle_image` отсутствует, runtime использует `image`.

Для отдельных икон могут существовать:

```text
icons/candle/<slug>.webp
icons/png/<slug>.png
```

Они используются только когда это явно прописано в записи.

Нельзя использовать alpha/cutout от другой иконы: геометрия маски должна соответствовать конкретному изображению.

## Как добавить новую икону

На текущем этапе добавление контента не должно требовать изменения `index.html`.

Минимальный процесс:

1. выбрать источник изображения и проверить права;
2. подготовить основной JPG;
3. подготовить квадратный preview;
4. подготовить 48 px loading image с сохранённой композицией;
5. добавить новую запись в `data/icons.json`;
6. использовать новый уникальный numeric `id`;
7. не перенумеровывать существующие записи;
8. проверить каталог, поиск, detail, swipe, Info и Candle Mode.

Подробный рабочий процесс описан в [`instructions.md`](./instructions.md).

## Источники и credits

Источники отдельных изображений хранятся:

- непосредственно в `data/icons.json`;

## Deployment

Приложение полностью статическое и может размещаться на обычном static hosting.

В коде присутствует интеграция Vercel Insights. Проект также совместим со статическим размещением вроде GitHub Pages при сохранении текущих относительных путей.

Для Telegram Mini App web URL настраивается отдельно через Telegram Bot / Mini App configuration.
